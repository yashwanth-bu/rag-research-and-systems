A practical study and implementation of Retrieval-Augmented Generation (RAG), its architectural variations, alternative approaches, and emerging research. This repository focuses on understanding RAG systems by building implementations, experimenting with different architectures, exploring research papers, and developing production-level applications.

Each project explores concepts such as traditional RAG, knowledge representation, structured retrieval, knowledge graphs, hybrid retrieval, agentic architectures, long-context generation, knowledge augmentation, and alternative approaches to retrieval and generation. The repository covers implementations from fundamental concepts to advanced research and evolving approaches that address the limitations of existing RAG systems.

## Objectives

- Understand the fundamental concepts and architectures of Retrieval-Augmented Generation.
- Implement RAG systems from scratch and explore their internal mechanisms.
- Explore different RAG architectures, retrieval strategies, and knowledge representation approaches.
- Study alternative approaches and architectural improvements to traditional RAG.
- Understand and experiment with emerging research in knowledge retrieval and generation.
- Develop custom RAG implementations, orchestration systems, and architectural designs.
- Build production-oriented applications using different RAG approaches.
- Study research papers and reproduce their concepts through implementations.

### Prerequisites

- Python 3.10 or later
- Basic programming knowledge (Python).
- Fundamental understanding of Machine Learning and Natural Language Processing.
- Basic understanding of APIs and backend development.
- Git installed on your system.

### Clone the Repository

```bash
git clone https://github.com/yashwanth-bu/rag-research-and-systems.git
```

Install the required dependencies specified by individual projects before running them.

```Python
pip install -r requirements.txt
```
